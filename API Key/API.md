# API Key (Application Programming Interface Key) 가이드

API Key(응용 프로그램 프로그래밍 인터페이스 키)는 외부 소프트웨어, 서비스, 또는 플랫폼(예: OpenAI, Google Maps, 공공 데이터 포털 등)의 기능에 접근하고 데이터를 주고받을 수 있도록 인증해 주는 고유한 문자열 식별자입니다. 서비스 제공자는 이 키를 통해 요청을 보낸 주체를 확인하고 사용량 제한, 과금, 보안 정책을 관리합니다.

---

## 1. API Key 사용 시 주요 주의사항

* **비용 폭탄 위험**: 상용 API의 경우 키가 탈취되면 제3자가 무단으로 대규모 요청을 보내어 천문학적인 사용료가 청구될 수 있습니다.
* **공개 저장소 노출**: 깃허브(GitHub) 등 소스코드 관리 플랫폼에 키를 그대로 업로드하면 봇(Bot)에 의해 실시간으로 스캔되어 악용됩니다.
* **권한 남용 (Over-privilege)**: 하나의 키에 너무 많은 권한(읽기, 쓰기, 삭제 등)을 한 번에 부여하면, 키가 유출되었을 때 피해 범위가 지나치게 넓어집니다.

---

## 2. 안전한 API Key 관리 방법

1. **환경 변수(.env) 활용**: 코드에 직접 키를 하드코딩하지 않고, 시스템 환경 변수나 설정 파일을 통해 불러오도록 설정합니다.
2. **`.gitignore` 설정 필수**: 소스코드 저장소에 `.env` 파일이나 설정 파일이 올라가지 않도록 `.gitignore`에 반드시 등록합니다.
3. **요청 출처 제한 (IP 및 도메인)**: API 관리자 콘솔에서 특정 IP 주소나 허용된 도메인(웹사이트 주소)에서만 키가 작동하도록 설정합니다.
4. **최소 권한 원칙 적용**: 필요한 최소한의 기능(예: 읽기 전용)만 수행할 수 있도록 권한을 엄격하게 분리하여 발급합니다.
5. **주기적인 키 로테이션 (Rotation)**: 일정 주기로 기존 키를 폐기하고 새로운 키를 발급받아 잠재적인 유출 위험을 차단합니다.
