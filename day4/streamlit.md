# Streamlit
### 1. 기본: 웹 앱 빌드와 기본 출력
    핵심 개념
    * Streamlit: 파이썬만으로 빠르게 웹 애플리케이션을 만들 수 있는 라이브러리
    * st.write(): 텍스트, 데이터, 마크다운 등을 유연하게 출력하는 기본 함수
    * 자동 리렌더링(Re-run): 코드 변경 시 웹 화면 실시간 반영
    * 레이아웃 구성: title, header 등을 통한 화면 구성

### 2. 실전: 인터랙티브 위젯과 레이아웃
    핵심 개념
    st.button()
    st.text_input()
    st.sidebar
    Session State
    사용자 입력값 활용

    if st.button("버튼"): 
        st.write("클릭됨!")


### 3. UI 구성 → 사용자 입력 → 데이터 시각화

Streamlit의 역할은 복잡한 웹 기술 없이 파이썬 코드만으로 인터랙티브한 대시보드를 구축하는 것

**st.selectbox()는 드롭다운 선택 메뉴를 만들고**, 
**st.dataframe()은 표 형식의 데이터를 화면에 출력**

|단계 | 배울 것 |   핵심
|---|---|---|
|1 |    기본 출력 | 텍스트 및 기본 컴포넌트 렌더링
|2 |    위젯 활용 |   사용자 입력 및 상호작용 처리
|3 |    대시보드 구축 | 실무에서 데이터 시각화 + 웹 앱 배포
