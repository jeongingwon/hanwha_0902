# Debugging
### 1. 기본: 에러 탐지와 프로그램 흐름 파악
    핵심 개념
    * Bug: 코드의 예상치 못한 오류나 잘못된 동작
    * Breakpoint: 코드 실행을 특정 지점에서 멈추게 하는 마커
    * Stack Trace: 에러 발생 시 경로와 원인을 추적하는 로그
    * 직관적 추적: 감으로 코드를 고치는 대신 데이터 상태 직접 확인

### 2. 실전: 중단점, 단계별 실행, 변수 감시
    핵심 개념
    Breakpoint (🔴)
    Step Over
    Step Into
    Variables (변수 감시)

    F5키로 디버깅 시작
    변수 값 실시간 추적 및 모니터링


### 3. 코드 실행 → 상태 검사 → 원인 수정

디버깅의 역할은 코드가 멈춘 시점에 어떤 데이터가 흘러 다니는지 직접 들여다보는 것

**Step Over는 다음 줄로 이동** 하고, 
**Step Into는 함수 내부로 들어가서 세부 동작을 확인**

|단계 | 배울 것 |   핵심
|---|---|---|
|1 |    Breakpoint | 코드 일시 정지
|2 |    Step Over, Step Into |   실행 흐름 제어
|3 |    상태 모니터링 | 실무에서 오류 원인 추적 + 수정
