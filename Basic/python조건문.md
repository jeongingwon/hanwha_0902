# 🐍 파이썬 조건문과 while 반복문 개념 정리

파이썬의 흐름 제어 핵심 문법인 **조건문(if)**과 **while 반복문**을 초보자 눈높이에 맞춰 정리한 가이드 문서입니다.

---

## 1. 개요 및 핵심 개념

파이썬 프로그램이 조건에 따라 다른 실행을 하거나, 특정 조건을 만족하는 동안 작업을 반복하도록 제어하는 핵심 문법입니다.

### 핵심 문법 요약
* **`if / elif / else`**: 주어진 조건식의 참(True)/거짓(False) 여부에 따라 실행할 코드 블록을 선택합니다.
* **`while`**: 조건식이 참(True)인 동안 블록 내부의 코드를 계속해서 반복 실행합니다.
* **`break`**: 반복문 실행 중 조건과 상관없이 즉시 반복을 종료하고 탈출합니다.
* **`continue`**: 아래 남은 코드를 실행하지 않고 다음 반복 순서로 바로 넘어갑니다.

---

## 2. 조건문과 while문 주요 특징 비교

| 구분 | 조건문 (if 문) | 반복문 (while 문) |
| :--- | :--- | :--- |
| **주 목적** | 조건에 따른 코드 실행 선택 | 조건이 참인 동안 코드 반복 실행 |
| **실행 횟수** | 조건 충족 시 **1회** 실행 | 조건 충족 시 **N회(지속)** 반복 실행 |
| **탈출 방식** | 코드 실행 후 자동 진행 | 조건이 거짓이 되거나 `break` 사용 |
| **주요 활용** | 입력값 검증, 분기 처리 | 상태 유지, 반복 작업, 무한 루프 처리 |

---

## 3. 통합 코드 예제

조건문(`if-elif-else`), `while` 반복문, `break`, `continue`의 동작 흐름을 한눈에 확인할 수 있는 예제 코드입니다.

```python
# [통합 예제] 1부터 시작하여 숫자를 올리며 조건별로 다르게 처리하는 프로그램

count = 0

# count가 6보다 작은 동안 계속 반복
while count < 6:
    count += 1

    # 1. 특정 조건에서 건너뛰기 (continue)
    if count == 2:
        print(f"[{count}] 2는 건너뜁니다.")
        continue

    # 2. 조건에 따른 분기 처리 (if - elif - else)
    if count == 1:
        print(f"[{count}] 첫 번째 시작입니다.")
    elif count % 2 == 1:
        print(f"[{count}] 홀수입니다.")
    else:
        print(f"[{count}] 짝수입니다.")

    # 3. 특정 조건에서 반복 종료 (break)
    if count == 5:
        print(f"[{count}] 목표 숫자에 도달하여 반복을 종료합니다.")
        break
