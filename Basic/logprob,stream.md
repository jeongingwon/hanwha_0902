# Gemini API 핵심 기능 요약 가이드 (Stream & Logprob)

본 문서는 Gemini API의 대표적인 고급 기능인 **스트리밍(Stream)**과 **로그 확률(Logprob)**의 개념과 핵심 내용을 간결하게 요약한 가이드입니다.

---

## 1. Stream (실시간 스트리밍)

* **개념**: AI 응답이 모두 완성될 때까지 기다리지 않고, 생성되는 즉시 조각(Chunk) 단위로 실시간 출력하여 대기 시간을 없애는 기능
* **주요 특징**: 긴 답변 생성 시 체감 속도 극대화
* **핵심 코드**: `client.models.generate_content_stream()` 호출 후 반복문(`for chunk in response:`)으로 출력

예시-

대韩(출력 중...) -> 대한민(출력 중...) -> 대한민국의 역사는... 

-->> 대한민국의 역사는 오랜 세월 동안 다양한 왕조와 시대를 거쳐 발전해 왔습니다. 기원전 고조선부터 시작하여 삼국 시대(고구려, 백제, 신라), 통일신라와 발해, 고려, 조선을 거쳐 현대에 이르기까지...

---

## 2. Logprob (로그 확률, Log Probabilities)

* **개념**: 모델이 특정 토큰(단어 조각)을 선택할 때의 **확신 정도**를 자연로그 확률 값으로 반환하는 기능
* **값의 의미**:
  * `0`에 가까운 값 (`-0.0001` 등): 높은 확신 (명확한 사실)
  * 큰 음수 값 (`-2.5`, `-5.0` 등): 불확실성 높음 (고민한 토큰)
* **주요 활용처**: 응답 신뢰도 검증, 환각(Hallucination) 탐지, 분류 작업 품질 관리
* **설정 방법**: `types.GenerateContentConfig(response_logprobs=True, logprobs=3)` 활용
